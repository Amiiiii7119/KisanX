# KisanX Frontend Redesign

This package contains the redesigned KisanX landing frontend.

## Visual direction
- Near-black background
- Deep agricultural green
- Harvest orange accent
- No logo icon
- No cyan/teal theme
- Canvas plasma field in the hero
- Dark feature system matching the hero

## Install
From `frontend`:

```powershell
npm install lucide-react
```

No shader package is required by the included button.

## Replace
Copy the files in this package into your existing `frontend` folder, preserving the underscore filenames.

Then run:

```powershell
npm run build
npm run dev
```
